Пользователь вызвал движок ресерча с аргументом: `$ARGUMENTS`

Загрузи скилл `research-engine` (Skill tool) и работай по нему. Аргумент читается так:

- `new <тема>` — стадия 0: интейк. Собери периметр, финиш, профиль и корень, заведи движок скриптом `engine-init.mjs`. Останов на подтверждение периметра.
- `plan` — стадия 1: декомпозиция. Тема режется на ТЗ, пишутся `prompts/`, `synthesis-spec/` и карта «тема → свод». Список тем показывается пользователю до прогона.
- `run <stage>` — прогон стадии (`research`, `verify`, `synth`, `merge`, `critique`, `method`). Сначала `render-tasks.mjs`, затем исполнитель: в Claude Code — Workflow-скрипт из `workflows/`, в Codex — `fanout.mjs`. Партиями, а не всё разом.
- `audit` — `audit.mjs` по корню движка, разбор блокеров и предупреждений.
- `index` — `build-index.mjs`: карта сводов с номерами строк.
- `status` — прочитай `engine.json` и `state/run-log.md`, покажи, что сделано, что осталось и какая команда следующая.

Без аргумента — покажи статус текущего движка, если он есть в этом каталоге, иначе объясни, с чего начать.
